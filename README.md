# Terminal Spike

**Your terminal. In your pocket.**

SSH and Mosh on Android. Optimized for Fold, with full support for regular phones.
Open source. No ads or subscriptions. Android 8.0+.

- SSH and built-in Mosh, with tabs and scrollback.
- Run Codex and other command-line tools on your server.
- Herdr workspaces with touch navigation.
- Custom shortcut keys, snippets, themes and fonts.
- SFTP file transfers, Git diffs and code-server.

## Get started

1. Install the app, then add your server address, username and password or SSH key.
2. Connect and confirm your server’s fingerprint.

Mosh requires `mosh-server` on your server.

For setup help, open **Settings → User guide** in the app.
See [Herdr setup](docs/HERDR-SETUP.md) or the [browser & code-server guide](docs/EMBEDDED-BROWSER.md).
