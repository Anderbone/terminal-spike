# Building the single app with native Mosh

Mosh is an internal library, built automatically with `:app:assembleDebug` or the release APK/AAB.
The main application is GPL-3.0-or-later under [ADR-005](../docs/ADR-005-BUNDLED-MOSH.md).

## Pinned toolchain

- Linux x86-64 host.
- JDK 17 for Android compilation (the repository also runs Gradle successfully with its provisioned
  JDK 25 daemon JVM).
- Android SDK platform 37 and build tools selected by AGP 9.3.1.
- Android NDK r29, exact Gradle revision `29.0.14206865`.
- Host CMake 3.22 or newer, GNU Make, Bash, tar, sha256sum and a POSIX host C/C++ compiler. CMake and
  the host compiler build the pinned `protoc`; they do not enter the APK.

Install the NDK side-by-side under the Android SDK. Do not put its absolute path in Git. The native
build locates it from the SDK selected by Gradle and rejects any other NDK revision.

## Source verification and build

From the repository root:

```bash
mosh-core/scripts/verify-sources.sh
JAVA_HOME=/path/to/jdk25 ./gradlew :mosh-core:test \
  :mosh-core:lint \
  :mosh-core:assembleDebug \
  :mosh-core:assembleRelease \
  :mosh-core:assembleDebugAndroidTest
```

The Gradle native task performs these deterministic stages for both `arm64-v8a` and `x86_64`:

1. verify and extract the three checked-in official archives into the module build directory;
2. verify the checksums of the checked-in Mosh message sources generated by matching `protoc`
   3.21.12;
3. cross-compile static Protocol Buffers Lite and static GNU Nettle with public-key algorithms,
   shared libraries, fat dispatch, documentation and GMP disabled;
4. apply the recorded Android key-hygiene and UDP-socket patches with zero fuzz, then compile the
   project-owned Android poll/JNI adapter plus the pinned Mosh client libraries;
5. link `libmosh_extension.so` with hidden visibility and 16 KiB page alignment, retaining an
   unstripped local symbol file while AGP strips the release package.

Reproduce the checked-in Protocol Buffers C++ outputs independently with a host `protoc` built from
the pinned Protocol Buffers archive:

```bash
mosh-core/scripts/generate-protobuf.sh
```

The script compares every regenerated file byte-for-byte and verifies
`src/main/cpp/generated/SHA256SUMS`. Pass `--write` only when deliberately regenerating after a
reviewed source-version change.

Native output is generated under `mosh-core/build` and is never committed. The main APK is
`app/build/outputs/apk/debug/app-debug.apk`; there is no Mosh extension APK. Install it using
the guarded device helper in the root README. Device tests follow AGENTS.md.

## Complete Corresponding Source

From a clean, committed repository revision:

```bash
scripts/create-source-bundle.sh
```

The deterministic archive and SHA-256 file are written to `build/distributions`. A different
output directory can be supplied as the only argument. The archive contains the entire app,
API, core library, benchmark/test inputs, pinned native archives, generation inputs, patches,
licences, Gradle wrapper and build scripts. It excludes ignored credentials and build output.

After extracting, configure Android SDK and the pinned NDK, use JDK 25 for Gradle, and run:

```bash
./gradlew test lint :app:assembleDebug :app:assembleRelease :app:bundleRelease
```

The single debug app uses the builder's normal Android debug key. Release signing can use the
builder's own external key through the root README's signing inputs. Production certificates
are not hard-coded and there is no companion-signature requirement.
