# Historical standalone Mosh publication materials

These files preserve the standalone extension repository's publication records, store listing,
graphics, demonstration video and contribution/security documents during repository consolidation.
They describe the former two-application distribution and are **not current build or release
instructions**. Links in the imported files are retained as historical source content.

Source: <https://github.com/Anderbone/terminal-spike-mosh-extension>

Imported revision: `4fe63fd4e02225a4ecba3b993a28bd9db72029be` (2026-09-07 import).
`IMPORT.json` records the SHA-256 of every imported file. The original `v1.0.0` source release
remains available from the source repository; retaining it preserves source access for existing
extension users.

The source repository's implementation, tests, native archives, patches and generated native code
already match `mosh-api/` and `mosh-extension/` in the main repository byte for byte. The main
repository has newer SDK and extension version settings, so the older standalone Gradle files
have not replaced the current build. All component licences and notices are already retained
in the corresponding modules.

See [ADR-004](../../ADR-004-OPEN-SOURCE-APP.md) for the consolidation direction.
