# Play Console checklist

- [ ] Final product name, package ID, developer name, contact email, category, countries, and pricing
      approved.
- [ ] Production upload key stored outside Git and backed up securely.
- [ ] Main app and extension enrolled with compatible Play App Signing certificates.
- [ ] Signed AAB certificate and Play-generated APK certificate compatibility verified.
- [ ] Version code has never been consumed by an earlier upload.
- [ ] Public privacy-policy URL entered.
- [ ] Data safety form completed from the current artifact and policy definitions.
- [ ] `specialUse` foreground-service declaration and sanitized demonstration video accepted.
- [ ] Content rating and target-audience forms completed accurately.
- [ ] 512 × 512 icon, 1024 × 500 feature graphic, and release-accurate screenshots uploaded.
- [ ] Internal-track install/update tested with the paired main application.
- [ ] Play pre-launch report reviewed and actionable failures resolved.
- [ ] Real-device password/private-key bootstrap, resize, concurrent sessions, extension death,
      cleanup, and Wi-Fi/cellular/VPN roaming matrix passed.
- [ ] Matching Corresponding Source archive and SHA-256 published in a durable GitHub release.
- [ ] Store listing links to source, privacy policy, support, and the paired main application.
- [ ] GPL/installation-information, Play signing/key rotation, combined-listing, and Mosh trademark
      review recorded.
