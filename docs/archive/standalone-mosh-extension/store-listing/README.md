# Google Play listing package

This directory contains version-controlled inputs for the separate
`com.yanjiyu.terminalspike.mosh` listing.

- `metadata/en-US`: title and descriptions ready to paste into Play Console.
- `graphics`: 512 × 512 app icon and 1024 × 500 feature graphic, with SVG masters.
- `screenshots/phone`: release-accurate phone screenshots.
- `video`: privacy-redacted foreground-service demonstration for Play review.
- `DATA_SAFETY.md`: evidence for the package-level Data safety declaration.
- `FOREGROUND_SERVICE.md`: text and shot list for the `specialUse` declaration.
- `PLAY_CONSOLE_CHECKLIST.md`: submission gates that require the publisher account.

The extension should be listed as a free companion application that requires Terminal Spike. Do
not claim endorsement by the upstream Mosh project. Update screenshots whenever the launcher UI
changes materially.
