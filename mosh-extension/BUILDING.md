# Reproducible local build

Public distribution is blocked by `../docs/ADR-003-MOSH-EXTENSION-BOUNDARY.md`. These instructions
produce local/debug evaluation artifacts only.

## Pinned toolchain

- Linux x86-64 host.
- JDK 17 for Android compilation (the repository also runs Gradle successfully with its provisioned
  JDK 25 daemon JVM).
- Android SDK platform 37 and build tools selected by AGP 9.3.1.
- Android NDK r29, exact Gradle revision `29.0.14206865`.
- Host CMake 3.22 or newer, GNU Make, Bash, tar, sha256sum and a POSIX host C/C++ compiler. CMake and
  the host compiler build the pinned `protoc`; they do not enter the APK.

Install the NDK side-by-side under the Android SDK. Do not put its absolute path in Git. The native
build locates it from the SDK selected by Gradle and rejects any other NDK revision.

## Source verification and build

From the repository root:

```bash
mosh-extension/scripts/verify-sources.sh
JAVA_HOME=/path/to/jdk17 ./gradlew :mosh-extension:test \
  :mosh-extension:lint \
  :mosh-extension:assembleDebug \
  :mosh-extension:assembleRelease \
  :mosh-extension:assembleDebugAndroidTest
```

The Gradle native task performs these deterministic stages for both `arm64-v8a` and `x86_64`:

1. verify and extract the three checked-in official archives into the module build directory;
2. verify the checksums of the checked-in Mosh message sources generated by matching `protoc`
   3.21.12;
3. cross-compile static Protocol Buffers Lite and static GNU Nettle with public-key algorithms,
   shared libraries, fat dispatch, documentation and GMP disabled;
4. compile the project-owned Android poll/JNI adapter plus unmodified Mosh client libraries;
5. link `libmosh_extension.so` with hidden visibility and 16 KiB page alignment, retaining an
   unstripped local symbol file while AGP strips the release package.

Reproduce the checked-in Protocol Buffers C++ outputs independently with a host `protoc` built from
the pinned Protocol Buffers archive:

```bash
mosh-extension/scripts/generate-protobuf.sh
```

The script compares every regenerated file byte-for-byte and verifies
`src/main/cpp/generated/SHA256SUMS`. Pass `--write` only when deliberately regenerating after a
reviewed source-version change.

Native outputs live only under `mosh-extension/build` and must not be committed. The extension APK
has package `com.yanjiyu.terminalspike.mosh`; the main APK has package
`com.yanjiyu.terminalspike`. Install them independently and confirm the main app still provides SSH
with the extension uninstalled.

`scripts/fetch-sources.sh` can reconstruct a missing source archive from its canonical upstream URL,
but a distributable Corresponding Source bundle must include the archives directly and may not rely
on those URLs remaining available.

## Corresponding Source bundle

Create the standalone, deterministic source archive from the repository root:

```bash
mosh-extension/scripts/create-source-bundle.sh
```

The archive and adjacent SHA-256 file are written to `mosh-extension/build/distributions` by
default. An alternate output directory may be passed as the sole argument. The bundle contains the
two required modules, pinned native archives, generated inputs, patches, notices, minimal root build,
version catalog, and Gradle wrapper. It deliberately contains no main-application source or signing
material.

After extracting the archive, set `ANDROID_HOME` or install the Android SDK normally, install exact
NDK revision `29.0.14206865`, and run:

```bash
JAVA_HOME=/path/to/jdk17 ./gradlew :mosh-extension:test \
  :mosh-extension:lint \
  :mosh-extension:assembleDebug \
  :mosh-extension:assembleRelease
adb install -r mosh-extension/build/outputs/apk/debug/mosh-extension-debug.apk
```

The local debug APK uses the consumer's normal Android debug signer. No private signing key is
required to reproduce or install it. The main app must use a compatible signer to pass the extension
trust boundary; production signing and public distribution remain blocked by the ADR.
