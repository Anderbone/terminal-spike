# Terminal Spike Mosh extension Corresponding Source

This archive is the standalone Corresponding Source for the separately installed
`com.yanjiyu.terminalspike.mosh` Android application. It contains the GPL extension, permissive IPC
API, exact upstream/native archives, project modifications, generated-source provenance, notices,
and a minimal reproducible Gradle build. It intentionally excludes the private main application.

See `mosh-extension/BUILDING.md`, `mosh-extension/DEPENDENCIES.md`, and
`mosh-extension/THIRD_PARTY_NOTICES.md`. Public distribution remains blocked pending the review in
`docs/ADR-003-MOSH-EXTENSION-BOUNDARY.md`.
