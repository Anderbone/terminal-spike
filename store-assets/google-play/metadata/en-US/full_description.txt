Your terminal. Your tools. Wherever you are.

Connect to your servers with a native Android terminal built for SSH, Mosh, tmux and Herdr. Pick up a remote session, run your favourite command-line tools, move files and keep useful commands close at hand.

SSH and Mosh, together
• Connect with a password or SSH key
• Import or generate SSH keys and manage your saved identities
• Use built-in Mosh for terminal sessions across changing networks; no separate extension required
• Keep multiple terminal sessions open in tabs
• Verify server fingerprints, with clear warnings when a host key changes

Bring your remote workspace
• Choose and resume tmux sessions from the app
• Open Herdr sessions and navigate their spaces and panes
• Use the CLI tools installed on your own server
• Connect to SSH hosts over Tailscale using their reachable Tailscale IP or MagicDNS name, with Tailscale configured on your devices

Less typing. More doing.
• Save command snippets for the tasks you repeat
• Customize the extra-key bar with Ctrl, Esc, arrows and your own shortcuts
• Search terminal output, select text and copy what you need
• Review multiline commands before pasting
• Send a clipboard image to a connected SSH host

Files and port forwarding
• Browse, upload, download, rename and delete remote files with SFTP
• Save local and remote TCP port-forwarding rules per connection
• Open a remote development server in your phone's browser through a local SSH tunnel

Make the terminal yours
• Choose terminal themes, colours, fonts, text size and cursor style
• Adjust keyboard and input behaviour to suit the way you work
• Back up and restore your app data with an encrypted local archive

Your connections stay yours
No Terminal Spike account, ads, analytics or cloud sync. Connection profiles and settings stay on your device, with locally stored secrets protected using Android security.

You need a reachable server and valid credentials. Mosh requires mosh-server on the remote host; tmux and Herdr require their respective server-side tools. Tailscale is a separate service with its own setup and access rules. TCP forwarding uses SSH, including alongside a Mosh session.
