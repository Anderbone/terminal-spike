실제 작업에 맞게 설계된 빠른 Android 네이티브 터미널에서 서버에 연결하세요.

Terminal Spike는 연결 정보와 설정을 기기에 보관합니다. 계정, 광고, 사용 분석, 클라우드 동기화가 없습니다.

여러 세션에서 작업
• 비밀번호 또는 키로 인증하는 SSH 세션 열기
• 여러 터미널을 독립된 탭으로 관리
• 저장된 호스트에 다시 연결하고 필요에 따라 tmux 세션 선택
• 호스트 키를 엄격하게 확인하고 서버 키가 변경되면 명확한 경고 표시

원격 작업을 위한 도구
• SFTP로 원격 파일 탐색, 업로드, 다운로드, 이름 변경 및 삭제
• 자주 사용하는 명령어를 스니펫으로 저장
• Ctrl, Esc, 화살표 및 원하는 단축키로 추가 키 표시줄 맞춤 설정
• 터미널 출력 검색 및 선택한 텍스트 복사
• 여러 줄 명령을 확인 후 붙여넣기
• 클립보드 이미지를 연결된 SSH 호스트로 보내 원격 도구에서 참조

나에게 맞게 설정
• 터미널 색상, 글꼴, 글자 크기, 커서 스타일 및 키보드 동작 선택
• 암호화된 로컬 보관 파일로 앱 데이터 백업 및 복원
• Android 보안 기능으로 기기에 저장된 비밀 정보 보호

Terminal Spike는 SSH 클라이언트입니다. SSH 서버 접근 권한과 유효한 인증 정보가 필요합니다. 네트워크 데이터는 사용자가 선택한 호스트하고만 교환됩니다. 일부 선택 기능은 원격 서버에 설치된 소프트웨어에 따라 달라질 수 있습니다.
